Kolm sammu

  1. Loo fail src/main/resources/static/index.html

    Kausta static projektis veel pole, loo see. Kleebi faili allolev kood täpselt sellisena. Spring Boot serveerib kõik static kaustas oleva automaatselt aadressilt /.

  2. Taaskäivita rakendus

    Peata jooksev bootRun (Ctrl+C) ja käivita uuesti: ./gradlew bootRun. Staatilised failid loetakse ainult käivitusel, ilma taaskäivituseta näed 404-i.

  3. Ava Chrome'is http://localhost:8080/

    Vajuta 🎤 Räägi, luba mikrofon, küsi näiteks „Mitu klienti meil on?". Kui lause lõpeb, saadetakse küsimus ise ära ja vastus ilmub alla. Enne 4. sammu on vastus SQL-lause, pärast seda lause loomulikus keeles.

Kui ei tööta

Nupp „Räägi" on hall ja kiri „Kõnetuvastus vajab Chrome'i"
Oled Safaris või Firefoxis. Ava sama aadress Chrome'is.
Mikrofoni luba ei küsitud või andsid „Keela"
Aadressiribal klõpsa lukuikooni → Mikrofon → Luba, siis värskenda lehte.
Viga network
Google'i kõneserver pole kättesaadav (VPN, tulemüür, võrk maas). Kirjuta küsimus kasti käsitsi ja vajuta Küsi.
Viga not-allowed
macOS-is: Süsteemiseaded → Privaatsus ja turvalisus → Mikrofon → luba Chrome.
Leht annab 404
Fail on vales kaustas või rakendust ei taaskäivitatud. Tee peab olema täpselt src/main/resources/static/index.html.
Vastus on Viga 500
Probleem on Java pooles, mitte lehes. Vaata sama küsimust Swaggeris ja rakenduse logi.

Boonus 2: häälvastus (Jutusta.ee)

Nüüd räägib rakendus ka vastu. Kõne sünteesib Jutusta.ee (eesti keele TTS, ElevenLabs-ühilduv API). Võti jääb Java poolele, brauser saab ainult heli. Vaja on kolme muudatust: üks uus Java-klass, kaks rida properties-faili ja väike lisa lehele.

  1. Tee Jutusta konto ja oma võti

    Registreeru jutusta.ee, arendaja lehelt loo API võti (algab sk_jt_). Igaühel on oma võti, seda ei jagata. Häälte loend: curl -H "xi-api-key: $JUTUSTA_API_KEY" https://jutusta.ee/api/v1/voices. Preset-hääled on nt mari, liina, jaan, mart.

  2. Lisa application.properties lõppu

jutusta.voice-id=${JUTUSTA_VOICE_ID:mari}

    Võti ei lähe faili, vaid keskkonnamuutujasse. Käivitamine:

./gradlew bootRun

  3. Loo src/main/java/com/example/ecommerce/controller/SpeechController.java

    Uus endpoint POST /api/speak: võtab JSON-i {"text": "..."}, kutsub Jutusta TTS-i ja tagastab WAV-i. Kasutab Spring 6 RestClient-i, lisasõltuvusi pole vaja.

    package com.example.ecommerce.controller;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.client.RestClient;

import java.util.Map;

/**
 * Häälväljund: tekst → Jutusta.ee TTS → WAV.
 * Võti jääb serverisse; brauser saab ainult heli.
 */
@RestController
@RequestMapping("/api/speak")
public class SpeechController {

    private final RestClient client;
    private final String voiceId;
    private final boolean enabled;

    public SpeechController(@Value("${jutusta.api-key}") String apiKey,
                            @Value("${jutusta.voice-id}") String voiceId) {
        this.enabled = apiKey != null && !apiKey.isBlank();
        this.voiceId = voiceId;
        this.client = RestClient.builder()
                .baseUrl("https://jutusta.ee/api/v1")
                .defaultHeader("xi-api-key", apiKey == null ? "" : apiKey)
                .build();
    }

    public record SpeakRequest(String text) {}

    @PostMapping(produces = "audio/wav")
    public ResponseEntity<byte[]> speak(@RequestBody SpeakRequest req) {
        if (!enabled) {
            return ResponseEntity.status(503).build();
        }
        String text = req.text() == null ? "" : req.text().strip();
        if (text.isEmpty()) {
            return ResponseEntity.badRequest().build();
        }
        if (text.length() > 2000) {
            text = text.substring(0, 2000);
        }
        byte[] wav = client.post()
                .uri("/text-to-speech/{voice}?output_format=wav", voiceId)
                .contentType(MediaType.APPLICATION_JSON)
                .body(Map.of("text", text, "voice_settings", Map.of("speed", 1.0)))
                .retrieve()
                .body(byte[].class);
        return ResponseEntity.ok()
                .header("Content-Type", "audio/wav")
                .body(wav);
    }
}

    Kolm lisa: linnuke ja peidetud helielement, üks rida ask() sisse ning kaks funktsiooni. Nupp „Kuula vastust" ilmub ainult siis, kui Chrome automaatset mängimist ei luba (see juhtub, kui lehel pole veel klikitud).

if (r.ok && $('tts').checked) speak(spokenForm(data.answer ?? ''));

// 3) uued funktsioonid:
function spokenForm(a) {
  const t = a.trim();
  if (t === 'CANNOT_ANSWER') return 'Sellele küsimusele ma andmebaasist vastata ei oska.';
  if (/^\s*select\b/i.test(t)) return 'Koostasin SQL-päringu.';
  return t;
}

async function speak(text) {
  if (!text) return;
  try {
    const r = await fetch('/api/speak', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ text })
    });
    if (!r.ok) { $('status').textContent = 'Häälväljund ei tööta (' + r.status + ')'; return; }
    const p = $('player');
    p.src = URL.createObjectURL(await r.blob());
    $('listen').hidden = true;
    try { await p.play(); }
    catch (err) { $('listen').hidden = false; $('status').textContent = 'Chrome ootab klikki, et heli mängida.'; }
  } catch (e) { $('status').textContent = 'Häälväljundi viga: ' + e.message; }
}

$('listen').onclick = () => { $('listen').hidden = true; $('status').textContent = ''; $('player').play(); };
